# Vietnam Pen Show

Website tĩnh cho Vietnam Pen Show (vietnampenshow.com).

- `index.html`: trang chính, thông tin thường niên
- `2026.html`: trang Mùa 2026, 05 đến 06.12.2026 tại Hồ Văn, Văn Miếu Quốc Tử Giám
- `img/`: logo và hình ảnh

Không cần build. Mở `index.html` trong trình duyệt để xem, hoặc bật GitHub Pages (Settings › Pages › Deploy from branch `main`, thư mục `/`).
